> 1. tag 必须为 `v{版本}`、安装包文件名必须为 `Ink.Canvas.Ultra.V{版本}.Setup.exe`，否则自动更新会 404。
> 2. "代码签名"一节：**仅在启用 SignPath Foundation 证书签名后保留**；未签名版本发布时删除该节。
> 3. SignPath 申请要求下载页提及签名方，签名上线后请勿删除该节。
