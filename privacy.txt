Ink Canvas Ultra 隐私政策
最后更新：2026-11-20

Ink Canvas Ultra（以下称"本软件"）是一款基于 GPLv3 许可证开源的电子白板软件。本政策如实说明本软件处理信息的实际方式。

一、核心承诺
    1. 本软件没有账号系统，不需要注册或登录，不收集任何个人身份信息。
    2. 本软件不含遥测、使用统计、广告或崩溃上报组件；您的书写墨迹、截图、白板文件、设置等全部用户数据仅保存在您自己的电脑上。
    3. 本软件向网络发出的所有请求均为"下载文件"（HTTP GET），不会向任何服务器上传您的用户数据。

二、网络访问说明（均为下载行为）
    1. 更新检查：程序启动时会从以下地址之一读取一个纯文本版本号文件，用于判断是否有新版本：
        - https://gh.muqiu.eu.org（维护者自建 GitHub 镜像）
        - https://cdn.jsdelivr.net（jsDelivr CDN）
        - https://raw.githubusercontent.com（GitHub 原始文件）
    2. 自动更新：当您确认更新后，才会从 GitHub Releases（经 gh.muqiu.eu.org 镜像或 GitHub 直连）下载安装包；您也可以选择忽略某个版本或继续使用当前版本。
    3. 插件工坊：仅当您打开插件工坊窗口并浏览或安装插件时，才会访问插件市场清单与插件文件（plugin.muqiu.eu.org、GitHub、jsDelivr 等），插件均为公开开源仓库中的文件。
    4. 下载代理：您可在设置中自定义下载代理前缀（默认 ghproxy.net），用于加速 GitHub 资源访问。
    5. 浏览器跳转：计算器（Desmos，desmos.com）与更新日志（doc.muqiu.eu.org）在您的浏览器中打开，按相应网站自身的隐私政策处理，本软件不介入。

三、第三方服务
    上述下载源由 GitHub、jsDelivr、ghproxy.net 及维护者自建镜像（*.muqiu.eu.org）提供。发出下载请求时，这些服务方可能获知您的 IP 地址与访问时间（任何网络请求的普遍情况），此外不会获得您的其他信息。相关隐私政策：
        - GitHub：https://docs.github.com/site/privacy/github-privacy-statement
        - jsDelivr：https://www.jsdelivr.com/privacy-policy-jsdelivr-net
        - ghproxy.net / *.muqiu.eu.org：镜像加速服务，仅转发文件请求，不额外收集用户数据
        - Desmos：https://desmos.com/legal/privacy（仅当您主动打开计算器时访问）

四、政策的适用与变更
    1. 本政策仅适用于 Ink Canvas Ultra 主程序；您自行安装的第三方插件由其作者负责，建议安装前查阅其源码仓库。
    2. 若本政策发生实质性变更，将在新版本发布时同步更新本文件并在更新日志中说明。
